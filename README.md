# 🧠 Dual Agency Pathways

Neural mechanisms underlying perceptual shifts of action--outcome binding under voluntary and involuntary conditions.

This repository contains the full computational analysis pipeline supporting the manuscript:

> *Dual neural pathways for agency: Distinct spatiotemporal signatures of action binding and outcome binding in the human brain.*

All analyses are modularized and aligned directly with the structure of the manuscript.

| 01_temporal_binding_effect | Temporal binding effect                                                                            | Compare perceptual shifts in different conditions                                                           |

-   Model implementation functions
-   Plotting utilities
-   Reproducible analysis scripts (`.Rmd`, `.ipynb`, `.m`)

## ▶ Reproducibility

All analyses are executed from the project root directory:

``` r
setwd("dual-agency-pathways")
```

Example: Reproduce temporal binding analysis

``` r
rmarkdown::render("analysis/01_temporal_binding_effect/01_temporal_binding_effect.Rmd")
```

Outputs will be written automatically to:

```         
results/01_temporal_binding_effect/
figures/01_temporal_binding_effect/
```

Each module can be run independently.

Some modules contain multiple sequential steps that should be executed in order. For example, the `05_LMM` module follows this workflow:

1.  `05_1_features_save.ipynb` -- Feature extraction
2.  `05_2_ITPC_save.ipynb` -- ITPC computation
3.  `run_plot_itpc_rose_all_05_3.m` -- Phase visualization
4.  `05_4_LMM.Rmd` -- Linear mixed-effects modeling

Scripts within such modules are numbered to indicate execution order.

# 🔁 Analytical Workflow

The repository is structured to mirror the conceptual and analytical progression of the manuscript.

1.  **Temporal binding effect** -- Behavioral quantification of perceptual shifts across different conditions.
2.  **MEG results** -- Visualization of region- and condition-specific stimulus-locked MEG responses.
3.  **Functional regression** -- Modeling behavioral responses as a function of MEG signals across experimental conditions and regions of interest.
4.  **Functional connectivity network** -- Directed connectivity estimation and network-level characterization.
5.  **Single-trial frequency analysis** -- Time--frequency feature extraction, ITPC characterization, and linear mixed-effects modeling.
6.  **sEEG results** -- Intracranial validation of the identified neural signatures.

Directory numbering across `analysis/`, `data/`, `results/`, and `figures/` reflects this analytical sequence to ensure internal coherence and reproducibility.
